- Surprises: raising `ship.mass` to 40000 to make close-range tug visible broke two PRE-EXISTING integration tests (ship_flight_test.lua's "empty tank disables thrust", landing_test.lua's "dropped slowly onto a world lands") that spawn an unrelated second ship only 60px away and assumed zero cross-ship gravitational effect — an assumption slice 06 legitimately invalidates. The orchestrator's own re-verification (not the subagent's, which had reported all green) caught this. Root cause: the point-mass law falls off as 1/r², so even a "far" 5000px separation still produced ~0.14 px/s² of residual pull — 1,000,000px was needed to get it under the tests' 0.01 tolerance. Fixed by moving each test's unused second ship to that distance rather than changing the mass/gravity tuning, preserving both the new pairwise-gravity feature and the old tests' original documented intent (isolating ship 1's own thrust/gravity behaviour).
