# GRAV//TY

Two-player local vector-style space duel with polygon worlds and gravity. Built with LÖVE (11.5 and 12) and LuaJIT.

See `docs/ARCHITECTURE.md` for the architecture and `docs/CONTEXT.md` for the glossary.
